I'm a Flutter developer, and this week I started learning .NET.

The goal is to build the whole product myself: database, API, web dashboard and mobile app.

Week 1 was small, but I learned more than I expected:

• In C#, 10 / 3 = 3. In Dart it's 3.33. Integer division cuts the decimals, which is an easy bug to miss.
• Console.ReadLine() always gives you text, even if the user types a number. You have to convert it first with int.Parse.
• My code worked, but my variable names were wrong (my "age" variable held the birth year 😅). Working code isn't the same as good code.

I also pushed my first project to GitHub. It's a tiny console app that asks your name and birth year and calculates your age:
